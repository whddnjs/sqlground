# 학습 요구사항

## 학습용 DB 되돌리기와 변경 표시
<!-- gitifact-req: R-bj2oscebzh -->

SQL 을 배우는 사용자로서, 예제를 마음껏 실행해도 연습장의 내 작업이 안전하고 언제든 처음 상태로 돌아갈 수 있다는 것을 알기 위해, 학습용 DB 의 되돌리기가 무엇을 하는지 분명히 보고 싶다.

### 수용 조건

1. 조건: 학습 또는 문제풀이 화면을 봅니다.
   기대 동작: "샘플 데이터 되돌리기" 버튼이 있고, 마우스를 올리면 학습용 DB 만 되돌리며 연습장은 그대로라는 설명이 나옵니다.
2. 조건: 데이터나 구조를 바꾸는 예제(UPDATE, DELETE, CREATE 등)를 실행합니다.
   기대 동작: 그 예제의 결과 아래에 데이터가 바뀌었다는 안내가 붙고, 되돌리기 버튼이 강조되며 "데이터가 바뀌었어요" 라고 알려 줍니다. 조회만 하는 예제는 아무 표시도 없습니다.
3. 조건: 되돌리기를 누릅니다.
   기대 동작: 학습용 DB 가 샘플 3종만 실린 처음 상태로 돌아가고, 강조와 안내가 사라지며, 예제들의 이전 실행 결과도 지워집니다. 연습장 DB 는 바뀌지 않습니다.
