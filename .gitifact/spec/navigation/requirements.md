# 화면 이동과 주소 요구사항

## 화면·단원·문제마다 주소
<!-- gitifact-req: R-deywsidxcj -->

SQL 을 배우는 사용자로서, 보던 단원이나 풀던 문제를 나중에 다시 열거나 다른 사람에게 알려 주기 위해 화면마다 고유한 주소가 있기를 바란다.

### 수용 조건

1. 조건: 사용자가 연습장, 학습, 문제풀이, 설정 메뉴 또는 특정 단원·문제로 이동합니다.
   기대 동작: 브라우저 주소가 그 화면을 가리키도록 바뀝니다. 연습장은 `/`, 단원은 `/learn/<단원 id>`, 문제는 `/problems/<문제 id>`, 설정은 `/settings` 입니다.
2. 조건: 사용자가 단원이나 문제 주소를 직접 열거나 새로고침합니다.
   기대 동작: 그 단원·문제가 바로 표시됩니다. 첫 화면을 거치지 않습니다.
3. 조건: 사용자가 브라우저 뒤로 가기·앞으로 가기를 누릅니다.
   기대 동작: 직전에 보던 화면(문제 → 관련 단원 → 다시 문제 등)으로 돌아가며 사이트를 벗어나지 않습니다.
4. 조건: 사용자가 단원·문제 id 없이 학습 또는 문제풀이 메뉴를 엽니다.
   기대 동작: 마지막에 보던 단원·문제로 이동하고, 없으면 첫 단원·문제로 이동합니다.
5. 조건: 존재하지 않는 단원·문제 id 나 알 수 없는 주소를 엽니다.
   기대 동작: 각각 첫 단원·첫 문제, 연습장으로 대신 이동합니다. 오류 화면을 보이지 않습니다.

### 범위와 제약

- 주소에는 화면 위치만 담는다. DB 내용이나 쿼리 본문은 주소에 넣지 않는다 (URL 공유 기능은 별도).
