# 설정 요구사항

## 코드 글꼴 합자 켜고 끄기
<!-- gitifact-req: R-mnyuhy2oct -->

SQL 을 배우는 사용자로서, `>=` `<>` `!=` 같은 연산자가 두 글자인지 한눈에 알 수 있도록 코드 글꼴의 합자를 끄거나, 익숙해진 뒤에는 켤 수 있기를 바란다.

### 수용 조건

1. 조건: 처음 방문하거나 설정을 바꾼 적이 없습니다.
   기대 동작: 합자는 꺼져 있어 연산자가 두 글자로 따로 보입니다.
2. 조건: 설정 화면의 에디터 절에서 "코드 글꼴 합자 사용" 을 켭니다.
   기대 동작: 연습장·학습·문제풀이의 에디터, 결과 그리드, 코드 조각, SQL 미리보기 등 코드 글꼴을 쓰는 모든 곳에 즉시 적용되고, 새로고침해도 유지됩니다.
3. 조건: 다시 끕니다.
   기대 동작: 같은 범위가 즉시 두 글자 표시로 돌아갑니다.

### 범위와 제약

- 이 설정은 사용자의 브라우저에만 저장된다.

## 진행 기록 초기화
<!-- gitifact-req: R-6p77ro3nzy -->

SQL 을 배우는 사용자로서, 처음부터 다시 공부하거나 다른 사람에게 브라우저를 넘겨줄 때를 위해 학습 완료 표시와 문제 해결 기록을 지우고 싶다.

### 수용 조건

1. 조건: 설정 화면을 엽니다.
   기대 동작: "진행 기록" 섹션에 "학습 완료 표시 초기화" 와 "문제 해결 기록 초기화" 버튼이 따로 있고, 각 버튼에 현재 완료·해결 수가 보입니다. 지울 기록이 없으면 그 버튼은 비활성입니다.
2. 조건: 버튼을 누릅니다.
   기대 동작: 무엇이 얼마나 지워지는지 적힌 확인창이 뜨고, 취소하면 아무것도 바뀌지 않습니다.
3. 조건: 학습 완료 표시 초기화를 확인합니다.
   기대 동작: 모든 단원의 완료 표시와 마지막에 보던 단원 위치가 지워집니다. 문제 해결 기록은 그대로입니다.
4. 조건: 문제 해결 기록 초기화를 확인합니다.
   기대 동작: 모든 문제의 해결 표시, 작성해 두었던 답안, 마지막에 풀던 문제 위치가 지워집니다. 학습 완료 표시는 그대로입니다.

### 범위와 제약

- 초기화는 되돌릴 수 없다. 연습장 DB 와 다른 설정에는 영향이 없다.
