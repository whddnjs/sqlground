# SQLGround

설치 없이 브라우저에서 바로 SQL 을 연습하는 웹사이트다. 링크를 열면 SQLite 가 브라우저 안에서 돌아가고, 쿼리 실행부터 테이블 생성·데이터 조작까지 모두 서버 없이 이루어진다. 공개 주소는 https://sqlground.vercel.app 이다.

## 누구를 위해

- SQL 을 처음 배우는 사람. DB 와 에디터를 설치하고 DB 종류마다 환경을 다시 맞추는 번거로움 없이 바로 연습하고 싶은 사람
- 특히 "SQL 만 처음인 개발자". 테이블·행·열 같은 개념은 알지만 문법과 실무 패턴(JOIN, 집계, 서브쿼리, 트랜잭션)을 손으로 익히고 싶은 사람

## 무엇을 제공하는가

- **연습장**: SQL 에디터와 결과 그리드. 쿼리를 몰라도 UI 로 테이블을 만들고 행을 추가·수정·삭제할 수 있으며, 그때 실행되는 SQL 을 그대로 보여 준다
- **학습**: 순차 커리큘럼이면서 문법 사전 역할도 하는 단원들. 예제는 페이지 안에서 바로 실행되고, 연습장과 분리된 학습용 DB 에서 돌아간다
- **문제풀이**: 학습 단원에 연결된 문제. 내 쿼리 결과를 정답 결과와 값 기준으로 비교해 채점한다
- 샘플 데이터(쇼핑몰, 학교, 회사)와 관계도, 되돌리기, DB 파일 내보내기·가져오기

## 원칙

- **브라우저 안에서 끝난다.** 서버·로그인 없이 동작하고, 작업 내용은 사용자의 브라우저에 저장된다. 정적 호스팅만으로 배포된다
- **SQL 이 항상 보인다.** UI 로 조작한 것도 어떤 SQL 이 실행됐는지 노출한다. UI 는 SQL 을 대신하는 게 아니라 배우는 통로다
- **실수해도 안전하다.** 실행 전 상태로 되돌릴 수 있고, 끝나지 않는 쿼리는 중단할 수 있으며, 화면이 멈추지 않는다
- **실무 DB 처럼 동작한다.** FOREIGN KEY 제약을 기본으로 켜고, SQLite 가 다른 DB 와 다른 부분은 학습 내용에서 짚어 준다
- **초보자에게 친절하다.** 에러에는 한글 설명을 붙이고, 컬럼에는 한글 설명을 달 수 있으며, 테이블·컬럼 이름이 자동완성된다

## 범위 밖

- 여러 사용자 간 공유·협업, 계정과 클라우드 저장 (향후 후보이나 현재 범위 아님)
- SQLite 외 DB 엔진 (PostgreSQL 은 향후 후보)
- 모바일 화면 최적화 (현재 데스크톱 전용)
- 실제 운영 데이터 관리 도구로서의 용도. 연습과 학습이 목적이다
